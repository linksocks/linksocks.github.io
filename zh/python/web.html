Web 类 ​

把本地 HTTP(S) 网站发布到 linksocks.js 中继。请求复用同一条 WebSocket 隧道，源站可以位于 NAT 之后，无需公网 IP 或入站端口。

概述 ​

python
from linksocks import Web

with Web(["http://127.0.0.1:8080"], url="wss://l.zetx.tech") as site:
    host = site.wait_ready(timeout=30)
    print(f"已发布：https://{host}")

中继会在其 WEB_ZONE 下分配临时域名，也可以用 domain_prefix 指定自定义域名前缀。 传入多个 backend 时按轮询方式转发。前缀需要中继方授权，未授权的账号会被拒绝。

构造函数 ​

python
Web(
    backends: list[str],
    *,
    url: str = "ws://localhost:8765",
    token: str = "",
    domain_prefix: Optional[str] = None,
    error_page: Optional[str] = None,
    insecure: bool = False,
    no_reconnect: bool = False,
    reconnect_delay: Optional[DurationLike] = None,
    logger: Optional[logging.Logger] = None,
)
参数类型默认值说明
backendslist[str]必填本地 HTTP(S) 源站地址
urlstr"ws://localhost:8765"linksocks.js 服务地址
tokenstr""控制台 Provider token
domain_prefixstr | NoneNone中继 WEB_ZONE 下的自定义前缀，例如 blog 对应 blog.<WEB_ZONE>
error_pagestr | NoneNone请求失败时向访客展示的 HTML 文件路径；可使用 、、
insecureboolFalse跳过 HTTPS 源站的证书校验
no_reconnectboolFalse中继断开后停止运行
reconnect_delayDurationLikeNone重连间隔
loggerlogging.LoggerNone接收中继日志的 Python logger

方法 ​

wait_ready(timeout=None) ​

阻塞直到站点注册完成，返回分配到的域名。

python
site.wait_ready()
site.wait_ready(timeout=30)
site.wait_ready(timeout="1m")

async_wait_ready(timeout=None) ​

wait_ready 的异步版本。

close() ​

停止 Provider 并释放中继注册。

async_close() ​

close 的异步版本。

属性 ​

host ​

当前远端域名；临时网址轮换后该值会更新。

python
print(site.host)

异步示例 ​

python
import asyncio
from linksocks import Web


async def main():
    async with Web(
        ["http://127.0.0.1:8080", "http://127.0.0.1:8081"],
        url="wss://l.zetx.tech",
        domain_prefix="blog",
    ) as site:
        print(f"已发布：https://{site.host}")
        await asyncio.Future()


asyncio.run(main())

async with Web(...) 会在进入代码块前等待注册完成。同步的 with Web(...) 不会等待，需要在块内调用 wait_ready() 获取域名。

命令行 ​

安装后的 linksocks 命令提供同样的能力：

bash
# 临时域名
linksocks web -u wss://l.zetx.tech -l http://127.0.0.1:8080

# 控制台 token、自定义域名前缀和两个源站
linksocks web -u wss://l.zetx.tech -t ls_xxx \
  --domain-prefix blog \
  -l http://127.0.0.1:8080 -l http://127.0.0.1:8081
