Web Class ​

Publish a local HTTP(S) site through a linksocks.js relay. Requests reuse the WebSocket tunnel, so the origin stays behind NAT with no public IP or inbound port.

Overview ​

python
from linksocks import Web

with Web(["http://127.0.0.1:8080"], url="wss://l.zetx.tech") as site:
    host = site.wait_ready(timeout=30)
    print(f"Published at https://{host}")

The relay returns a temporary hostname under its WEB_ZONE, or a hostname under a prefix passed in domain_prefix. Several backends are served round-robin. A domain_prefix requires the relay to allow it: an account without the hostname grant is refused.

Methods ​

wait_ready(timeout=None) ​

Block until the site is registered and return the assigned hostname.

python
site.wait_ready()
site.wait_ready(timeout=30)
site.wait_ready(timeout="1m")

async_wait_ready(timeout=None) ​

Async variant of wait_ready.

close() ​

Stop the provider and release the relay registration.

async_close() ​

Async variant of close.

Properties ​

host ​

The current remote hostname. It changes when a temporary URL rotates.

python
print(site.host)

Async Example ​

python
import asyncio
from linksocks import Web


async def main():
    async with Web(
        ["http://127.0.0.1:8080", "http://127.0.0.1:8081"],
        url="wss://l.zetx.tech",
        domain_prefix="blog",
    ) as site:
        print(f"Published at https://{site.host}")
        await asyncio.Future()


asyncio.run(main())

async with Web(...) waits for registration before entering the block. The synchronous with Web(...) returns immediately; call wait_ready() inside the block when you need the hostname.

CLI ​

The installed linksocks command exposes the same provider:

bash
# Temporary hostname
linksocks web -u wss://l.zetx.tech -l http://127.0.0.1:8080

# Dashboard token, a domain prefix of your own and two origins
linksocks web -u wss://l.zetx.tech -t ls_xxx \
  --domain-prefix blog \
  -l http://127.0.0.1:8080 -l http://127.0.0.1:8081
